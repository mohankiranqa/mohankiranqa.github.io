# Mohankiran Amalapurapu — QA Portfolio

A responsive static portfolio website built from the information in the supplied resume.

## Files
- `index.html` — page structure/content
- `styles.css` — responsive visual design
- `script.js` — mobile menu + current year

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a GitHub repository, e.g. `mohankiran-portfolio`.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. In GitHub: Settings → Pages → Deploy from branch → `main` / root.
4. Your site will be available at the GitHub Pages URL.

## Before publishing
- Replace/add the LinkedIn URL if your preferred profile URL changes.
- Add a professional headshot only if you want one.
- Add links to GitHub projects if you have public repositories.
- Do not publish your phone number if you prefer not to expose it publicly.
